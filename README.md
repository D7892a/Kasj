# كاشير ماكس — Cashier Max POS

نظام كاشير ومخزن كامل بملف واحد (`index.html`) يعمل في المتصفح مباشرة — بدون إنترنت، وبدون خادم، وبدون تثبيت أي برنامج.

---

## 1) كيف يشتغل النظام بالضبط؟

1. افتح الملف `index.html` في أي متصفح (كروم / إيدج) — يعمل على ويندوز أو لينكس أو ماك.
2. تظهر شاشة **تسجيل الدخول**:
   - اسم المستخدم: `admin`
   - كلمة المرور: `admin123`
3. بعد الدخول تظهر **الصفحة الرئيسية** وفيها 15 بطاقة — كل بطاقة تفتح شاشة من شاشات النظام.
4. كل عملية (بيع، شراء، إضافة مادة، مصروف، شخص، إعدادات…) تُحفظ **تلقائياً** في متصفح الجهاز نفسه، وتبقى محفوظة بعد إغلاق الصفحة أو إعادة تشغيل الجهاز.
5. الضغط على **X** في أعلى النافذة يسجل الخروج فقط (البيانات لا تُمسح).
6. للنسخ الاحتياطي: **الإدارة ← النسخة الاحتياطية ← تحميل نسخة JSON**، وللنقل لجهاز آخر: استورد نفس الملف.

> ⚠️ ملاحظة مهمة: البيانات تُحفظ في متصفح الجهاز نفسه (localStorage). إذا فتحت الملف على جهاز آخر أو متصفح آخر، ستظهر البيانات الافتراضية فقط — انقل بياناتك عبر نسخة JSON الاحتياطية.

## 2) كل الشاشات والمزايا الموجودة بالنظام

| الزر في الصفحة الرئيسية | ماذا يعمل؟ |
|---|---|
| **الكاشير** | واجهة البيع السريع: بحث + باركود + تصنيفات + بطاقات مواد + سلة + خصم + توصيل + كاش/دين + بيع + طباعة + تعليق/استئناف فاتورة |
| **الفاتورة** | فاتورة يدوية بيع أو شراء: اختيار مادة بالكود أو بالقائمة، تعديل السعر والعدد، خصم/توصيل/مدفوع، حفظ الفاتورة |
| **المخزن** | إضافة/تعديل/حذف مواد، إضافة تصنيفات، إضافة عدد للنواقص، بحث وتصفية، طباعة قائمة الجرد A4 |
| **المبيعات** | سجل كل فواتير البيع + ملخصات (كاش / دين / الإجمالي / العدد) + بحث + حذف + معاينة وطباعة |
| **المشتريات** | سجل فواتير الشراء + معاينة وطباعة |
| **الأشخاص** | الزبائن والموردين: إضافة، هاتف، عنوان، إجمالي التعامل، الدين المتبقي، زر تسديد الدين |
| **الإدارة** | 6 تبويبات: تفاصيل المشروع والشعار، سمات ألوان الفاتورة، معلومات الفاتورة المطبوعة، المستخدمين، الصلاحيات، النسخة الاحتياطية |
| **التقارير** | إجمالي المبيعات، الكاش، الديون، المصروفات، رأس مال المخزن، صافي الأرباح |
| **إدارة الصلاحيات** | فتح مباشر لتبويب الصلاحيات |
| **إدارة المصروفات** | تسجيل وحذف المصروفات وعرض إجماليها |
| **إضافة شخص** | نموذج إضافة زبون/مورد سريع |
| **إضافة مصروف** | نموذج تسجيل مصروف سريع |
| **التنبيهات** | الأشخاص المتأخرين عن التسديد وعدد أيام التأخير |
| **الوارد اليومي** | تكلفة الشراء، إجمالي المبيعات، صافي الربح لليوم المختار |
| **الحاسبة** | حاسبة ويندوز مدمجة (جمع/طرح/ضرب/قسمة/مسح/رجوع) |

## 3) الطباعة على ورق A4 — الإعداد الصحيح

تم ضبط الكود نفسه على مقاس A4 (مقاس `210mm × 297mm` مع هامش `10mm`)، ولضمان خروج الورقة 100% مضبوط اتبع هذه الخطوات في نافذة الطباعة:

1. اضغط زر **طباعة** داخل معاينة الفاتورة (أو داخل قائمة المخزن).
2. في نافذة الطباعة اختر:
   - **الطابعة**: طابعتك
   - **الورق (Paper / Size)**: `A4` عمودي (Portrait)
   - **الهوامش (Margins)**: `الافتراضي (Default)` أو `10mm` — لا تختار «بلا هوامش» إلا إذا أردت ملء الورقة كاملة
   - **المقياس (Scale)**: `100%` (تأكد أنها ليست «Fit to page» أو «تكبير/تصغير تلقائي» حتى لا تطلع الفاتورة أصغر أو أكبر)
   - **خيارات متقدمة**: فعّل **«طباعة الخلفيات والألوان» (Background graphics)** حتى تظهر ألوان جداول الفاتورة كاملة
3. اضغط **حفظ / طباعة**.

إذا كانت الطابعة تترك مسافة بلا طباعة على حافة الورقة: هذا طبيعي — الطابعات الليزرية/الحبرية لا تطبع حتى حافة الورقة، لكن المقاس والمحتوى يبقى مضبوطاً على A4.

## 4) أين تُحفظ البيانات؟

- تُحفظ تلقائياً بكل عملية داخل **ذاكرة المتصفح (localStorage)** بالمفتاح `cashierMaxState_v1`.
- للتنظيف الكامل أو البدء من جديد: **الإدارة ← النسخة الاحتياطية ← إعادة تعيين النظام**.
- للاسترجاع من ملف: **الإدارة ← النسخة الاحتياطية ← استيراد نسخة سابقة** (ملف JSON الذي صدّرته سابقاً).

## 5) أخطاء شائعة وحلولها

| المشكلة | الحل |
|---|---|
| بعد إغلاق الصفحة تختفي بياناتي | هذا كان الخلل القديم — الآن البيانات تُحفظ تلقائياً؛ تأكد أنك تستخدم النسخة المحدثة من `index.html` |
| الطباعة تطلع بمقاس غير A4 | اتبع خطوات القسم 3: اختر A4 + 100% + الهوامش الافتراضي |
| ألوان الفاتورة لا تطبع | فعّل «Background graphics» من نافذة الطباعة |
| نسيت كلمة المرور | منشئ النظام يجب أن يعدل الملف؛ المستخدم الافتراضي `admin / admin123` |
| أريد نقل البيانات لجهاز آخر | صدّر نسخة JSON من جهازك، ثم استوردها على الجهاز الآخر |

## 6) ملفات المشروع

- `index.html` — النظام كله (واجهة + منطق + قاعدة بيانات مبدئية) في ملف واحد.

لا يحتاج المشروع أي `npm install` ولا خادم — يكفي فتح `index.html`، أو رفعه على GitHub Pages / أي استضافة ملفات ثابتة.
